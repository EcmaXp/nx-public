# Herdr

Herdr organizes terminals into workspaces, tabs, and panes, recognizes coding agents running inside panes, and exposes the current session through the `herdr` CLI.

Before issuing any control command, verify that this agent is running inside a Herdr-managed pane:

```bash
test "${HERDR_ENV:-}" = 1
```

If the check fails, say that you are not running inside Herdr and stop.

When the check passes, load the skill that ships with the installed binary and follow it:

```bash
herdr --skill
```

That output is the authority for command syntax and safety rules of the installed version. Never run bare `herdr`: it launches or attaches the TUI.
